# HEADCRASH

**아레나는 플로피 디스크이고, 당신은 드라이브의 복구 루틴입니다.**
*The arena is the floppy disk. You are the drive's repair routine.*

소개 페이지 → **<https://jungrok5.github.io/headcrash-public/>**

2P Game Arcade **1.44MB 게임 개발 공모전** 출품작. 실행파일 하나, **927,744 바이트**,
플로피 한 장의 62.9%. 설치도 런타임도 필요 없고, 디스크에서 읽어오는 파일은 하나도
없습니다 — 메시도 음악도 효과음도 폰트도 전부 실행 중에 만들어냅니다.

이 저장소는 **소개 페이지**만 담고 있습니다.

```
index.html     the page
assets/        screenshots, clips and the video it shows
```

게임 안 타이틀 화면 왼쪽 아래의 QR 코드가 이 페이지를 가리킵니다. 게임 자체는
네트워크에 접속하지 않습니다 — QR은 화면에 그려진 그림일 뿐입니다.
